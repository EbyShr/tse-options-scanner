# وب‌اپلیکیشن اسکنر و رتبه‌بند اختیار معامله بورس تهران (TSETMC)

ابزار تحت وب و خط فرمان تحلیلی برای پایش، غربالگری، ارزش‌گذاری بلک-شولز، سنجش حباب، اهرم، نقدینگی واقعی و امتیازدهی یکپارچه نمادهای اختیار معامله (Call و Put) روی ۲۴ دارایی پایه بازار سرمایه ایران.

---

> ### ⚖ سلب مسئولیت حقوقی و ماهیت تحلیلی
> **صرفاً ابزار غربالگری و رصد بازار**: این نرم‌افزار هیچ‌گونه معامله‌ای انجام نمی‌دهد، سفارشی ارسال نمی‌کند و به هیچ کارگزاری متصل نیست. مسئولیت کامل استفاده از داده‌ها و اتخاذ هرگونه تصمیم سرمایه‌گذاری بر عهده کاربر است.
> 
> **محدودیت مدل بلک-شولز (BSM) در بورس تهران**: نرخ بازده بدون ریسک (Risk-Free Rate) و نوسان‌پذیری ضمنی (IV) در بازار آپشن ایران دارای بازار مشتقه عمیق مشابه استانداردهای جهانی نیستند. بنابراین، قیمت تئوریک BSM و عدد **«حباب»** یک تخمین مقایسه‌ای و نسبی برای مقایسه میان نمادهاست و نباید به عنوان ارزش قطعی تلقی گردد.

## ویژگی‌ها و امکانات نسخه جدید

### ۱. الگوریتم جدید امتیازدهی واحد (`calculate_score`)
فرمول واحد و یکپارچه در سراسر برنامه (جدول کل بازار و لیست‌های برتر) با مقیاس نرمال‌شده ۰ تا ۱۰۰:

| مؤلفه اصلی | وزن | جزییات و سازوکار |
| :--- | :---: | :--- |
| **آمادگی دارایی پایه** | **۳۵٪** | منطق نامتقارن Call و Put در ۴ جزء مساوی (روند SMA، شاخص RSI-14، صف و عمق بوک، پولبک) |
| **نقدینگی ترکیبی** | **۳۰٪** | **نقدینگی ساختاری (۱۸٪)** بر مبنای میانگین ۵ روزه ارزش و تعداد معاملات + **جهش لحظه‌ای (۱۲٪)** بر مبنای نسبت معامله امروز به ۵ روزه |
| **ارزش نسبی (حباب BSM)** | **۲۰٪** | رتبه صدکی معکوس حباب (قراردادهای منصفانه بالاترین امتیاز را دارند) |
| **تناسب سررسید (DTE)** | **۱۵٪** | منحنی پیوسته با قله در بازه بهینه ۱۰ تا ۴۰ روز تا سررسید |

#### مهار انفجار حباب در Deep OTM
در قراردادهای عمیقاً در زیان که $P_{\text{BSM}} < 10$ ریال یا $|\Delta| < 0.10$ است:
- حباب درصدی به علت مخرج نزدیک صفر برابر `N/A` نمایش داده می‌شود.
- اختلاف ریالی قیمت بازار و تئوریک در ستون **«حباب ریالی»** درج می‌شود.
- برچسب «اختیار عمیقاً بی‌ارزش / سفته‌بازی صرف» اعمال شده و این نمادها از لیست‌های پیشنهادی ورود خارج می‌شوند.

#### سقف ضد-Chasing (Anti-Chasing Penalty)
اگر دارایی پایه در ۳ روز اخیر بیش از ۱۵٪ رشد کرده باشد (برای Call) یا بیش از ۱۵٪ ریزش داشته باشد (برای Put)، ضریب احتیاط **۰.۷** در امتیاز آمادگی پایه ضرب می‌شود تا از ورود هیجانی به امواج فرسوده جلوگیری شود.

---

### ۲. تفکیک ۱۰ برتر خرید (Call) و فروش (Put) همراه با چارت راداری Plotly
- تب پیشنهادات برتر به دو زیرتب تفکیک شده است:
  - 📈 **۱۰ خرید برتر (Call)**
  - 🛡️ **۱۰ فروش برتر (Put)**
- **فیلترهای سخت ورود**:
  - حداقل ارزش معاملات روزانه: ۵۰۰ میلیون تومان (۵,۰۰۰ میلیون ریال)
  - حداقل تعداد معاملات: ۳۰ معامله در روز
  - حداقل روزهای تا سررسید: ۳ روز
  - عدم حضور در وضعیت Deep OTM
- **چارت راداری عنکبوتی (Plotly Radar Chart)**: نمایش بصری و گرافیکی توازن ۴ ضلع امتیاز برای هر کارت پیشنهادی.
- **تولید خودکار شرح امتیاز («چرا این امتیاز»)** بر مبنای قواعد فعال‌شده.
- **برچسب ظریف هشدار تمرکز**: هشدار رنگی در صورت تمرکز بیش از ۳ نماد برتر روی یک سهم پایه.

---

### ۳. بازطراحی ظاهری مدرن و موسساتی (Dark Navy / Light)
- **پالت تیره سازمانی (Dark Navy)**: ترکیب رنگ‌های `#0B132B` و `#1C2541` با کنتراست فونت Vazirmatn، تاکیدی‌های زمردی `#10B981`، یاقوتی `#F43F5E` و طلایی `#F59E0B`.
- **سوئیچ حالت تاریک/روشن**: تغییر بلادرنگ تم برنامه از سایدبار.
- **انیمیشن شناور نرم (Hover Effect)**: ترنزیشن ۰.۲۵ ثانیه روی کارت‌ها با جابجایی عمودی و تقویت سایه.
- **حذف بنرهای مزاحم**: انتقال تعاریف به تول‌تیپ `(i)` و درج فوتر تک‌خطی مینیمال.

---

### ۴. پوشش ۲۴ دارایی پایه و سرعت پردازش
پایش هم‌زمان کلیه قراردادهای اختیار متعلق به ۲۴ نماد پایه (بیش از ۱,۳۸۰ نماد فعال):
> **وبملت، خودرو، شستا، خساپا، وتجارت، فملی، اخابر، وبصادر، ذوب، شپنا، خبهمن، فرابورس، تاصیکو، بساما، اهرم، فزر، کاریس، دارونو، موج، توان، اطلس، جوانه کوچک، همتراز، طعام**

- استخراج موازی چندنخی با `ThreadPoolExecutor` در کسری از ثانیه.
- کش هوشمند محلی (`cache/market_data_cache.pkl`) با قابلیت بازیابی فوری.
- رفرش خودکار انتخابی (۳۰، ۶۰، ۱۲۰ ثانیه).

## راهنمای اجرا

### ۱. اجرای وب‌اپلیکیشن (Streamlit)
```bash
streamlit run app.py
```
سپس مرورگر را در آدرس `http://localhost:8501` باز کنید.

### ۲. اجرای خط فرمان (CLI / Cron)
برای دریافت داده‌ها و تولید فایل‌های گزارش روزانه اکسل و CSV:
```bash
python main.py
```

### ۳. اجرای تست‌های واحد
```bash
python -m unittest discover -s tests -p "test_*.py"
```
